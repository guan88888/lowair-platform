# Market feature

- Routes: all `pages/market/**` routes, including `pages/market/cart` and `pages/market/repair`.
- Owned files: `features/market/**` and thin market route shells.
- API boundary: catalogue, product detail, cart, inspection history, rental, repair providers/bookings, sell flow and orders belong in `services/`.
- Demo state: prices, stock, SN reports, inspection, escrow and blockchain labels are mock or pending-integration state.
